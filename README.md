> Командный проект в рамках ИШИТР+. Мобильное приложение и бэкенд для управления семейной группой, контроля тарифов, настройки лимитов и отслеживания потребления ресурсов (трафик, минуты) участниками в экосистеме Т-мобайл.

---

## 🔗 Экосистема проекта

Проект реализуется командой в рамках распределенной архитектуры. Данный репозиторий содержит **всю системную аналитику и документацию**. Связанные репозитории команды:

| Репозиторий | Описание | Ответственный | Статус |
| :--- | :--- | :---: | :---: |
| 🔗 [android-app](https://github.com/pomidorchik03/ishitr-t-mobile-android) | Мобильное приложение (Android) | @pomidorchik03 | 🟡 В разработке |
| 🔗 [backend](https://github.com/Razil131/ishitr-t-mobile-backend) | Основной микросервис управления тарифами | @Razil131 | 🟡 В разработке |
| 🔗 [generator]() | Генератор событий | @Razil131 | 🟡 В разработке |
| 🔗 [docs](https://github.com/shedoesacase/ishitr-t-mobile-docs) | Документация и аналитика | @shedoesacase | 🟡 В разработке |
